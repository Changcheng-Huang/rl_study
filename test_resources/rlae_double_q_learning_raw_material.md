# RLAE 原始资料：Double Q-Learning 教学内容采集稿

> 资料性质：这是内容提供者提交给平台的原始采集稿，不是 Theory 成品、
> Notebook、实验代码或算法安装包。以下信息允许 AI 做清理、归纳和模块化，
> 但所有公式、实验设定和动画方案在发布前仍需人工审核。

## 1. 为什么要讲这个算法

普通 Q-Learning 在更新时既使用同一组估计值选择动作，又使用这组估计值评价
所选动作。含噪声的动作价值估计经过 `max` 操作后，容易出现系统性的高估。
Double Q-Learning 的核心想法是把“选择”和“评价”拆开：维护两张独立的动作
价值表，一张表负责选动作，另一张表负责评价该动作。

希望学习者完成本节后能够：

- 解释 Q-Learning 中最大化偏差（maximization bias）的来源；
- 说清 `Q_A` 与 `Q_B` 如何交叉用于选择和评价；
- 根据一次转移手工计算一次 Double Q-Learning 更新；
- 在 FrozenLake 小环境中运行训练并读懂奖励曲线、成功率和最终策略；
- 区分“双 Q 表减少高估”与“完全消除所有估计误差”这两种说法。

## 2. 使用范围和前提

本资料讨论表格型、无模型、离策略控制算法。假设状态空间与动作空间有限，
可以为每个 `(state, action)` 保存数值。交互按 episode 组织，终止状态之后不再
bootstrap。行为策略使用基于 `Q_A + Q_B` 的 epsilon-greedy 策略。

输入包括：一个离散 Gymnasium 环境、训练回合数、学习率、折扣因子、探索率
和随机种子。输出包括：`Q_A`、`Q_B`、由两张表之和导出的贪心策略、每回合奖励、
滚动成功率，以及最终成功率摘要。

当前材料只承诺支持 `FrozenLake-v1`。建议教学实验使用 4×4 地图和
`is_slippery=False`，以便学习者把更新公式与确定性移动逐步对应。地图可采用：

```text
SFFF
FHFH
FFFH
HFFG
```

`S` 是起点，`F` 是安全冰面，`H` 是终止陷阱，`G` 是终止目标。动作为
0=Left、1=Down、2=Right、3=Up。到达目标奖励为 1，其余转移奖励为 0。

## 3. 核心记录

初始化两张动作价值表：

```text
Q_A(s,a) = 0
Q_B(s,a) = 0
```

选行为动作时使用两张表的和：

```text
a ~ epsilon_greedy(Q_A(s,·) + Q_B(s,·))
```

每次转移 `(s, a, r, s', terminated)` 后，以相同概率决定更新哪张表。
如果更新 `Q_A`，先用 `Q_A` 在下一状态选出动作，再用 `Q_B` 评价：

```text
a* = argmax_a Q_A(s',a)
target_A = r                                      if terminated
target_A = r + gamma * Q_B(s',a*)                 otherwise
Q_A(s,a) <- Q_A(s,a) + alpha * (target_A - Q_A(s,a))
```

如果更新 `Q_B`，两张表交换职责：

```text
b* = argmax_a Q_B(s',a)
target_B = r                                      if terminated
target_B = r + gamma * Q_A(s',b*)                 otherwise
Q_B(s,a) <- Q_B(s,a) + alpha * (target_B - Q_B(s,a))
```

相同最大值对应多个动作时，应在最大动作集合中随机打破平局，避免固定选择编号
最小的动作。训练完成后可用 `argmax_a (Q_A(s,a) + Q_B(s,a))` 生成最终策略。

## 4. 内容提供者手写的伪代码草稿

1. 创建环境，为 `Q_A` 和 `Q_B` 填零。
2. 对每个 episode 重置环境。
3. 在当前状态按 `Q_A + Q_B` 做 epsilon-greedy 选动作。
4. 执行动作并取得下一状态、奖励和终止标记。
5. 抛一次公平硬币，决定更新 A 表还是 B 表。
6. 用被更新的表选择下一动作，用另一张表评价下一动作。
7. 如果已经终止，则目标值只保留即时奖励。
8. 更新当前 `(state, action)`，然后进入下一状态。
9. episode 结束后记录奖励和是否成功。
10. 全部训练完成后返回指标、摘要和由两张表之和得到的策略。

## 5. 建议实验参数与需要展示的结果

建议默认值：

- `episodes`: 1500，整数，可调范围 100–10000，步长 100；
- `alpha`: 0.10，浮点数，可调范围 0.01–1.00，步长 0.01；
- `gamma`: 0.99，浮点数，可调范围 0.00–1.00，步长 0.01；
- `epsilon`: 0.10，浮点数，可调范围 0.00–1.00，步长 0.01；
- `seed`: 42，整数，可调范围 0–10000，步长 1。

实验运行期间至少报告 `episode_reward` 和每 100 回合的滚动成功率。结果摘要至少
包含总回合数、最后 100 回合成功率、访问过的状态—动作对数量。策略网格中，
陷阱和目标不显示动作箭头；其他格子显示两张表之和对应的最优动作。

功能正确性的最低人工检查：固定相同 seed 时结果可复现；`alpha=0` 若被界面
允许，则 Q 表不应变化；终止转移不得读取下一状态 Q 值；进度最终必须到达
总回合数；返回指标长度应与训练回合数一致。

## 6. Notebook 希望覆盖的练习，但尚未写成 Notebook

内容提供者希望学习者先观察一个“同一组含噪估计既选又评”的小例子，再补全
一次 A 表更新，随后运行 FrozenLake 训练。Notebook 应让学习者修改 epsilon 和
alpha，对比奖励曲线与策略变化，并包含至少三个不依赖网络的自检问题。

不要把“Double Q-Learning 一定比 Q-Learning 收敛更快”写成结论。本资料只主张
它通过分离选择和评价来降低由最大化操作引入的高估倾向。
