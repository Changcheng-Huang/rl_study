# AI 辅助强化学习内容创作扩展模块：项目交接摘要

## 项目概述

本项目是在现有强化学习教学网站上开发一个 AI 辅助内容创作扩展模块。现有
网站通过四种形式组织一个完整的算法教学单元：

1. **Theory**：理论解释、公式、示例和总结；
2. **Animation**：程序化教学动画；
3. **Notebook**：可执行代码、注释示例和练习；
4. **Experiment**：可交互的强化学习环境、参数和观察结果。

目前，人工制作一个完整教学单元耗时较长，同时要求制作者具备强化学习、
编程、动画和教学设计等多方面知识。因此，本项目希望让教师、助教和有技术
经验的内容创作者上传自己的资料，由多个协作 Agent 帮助生成结构统一、来源
可追溯、能够审核的教学内容。

## 核心原则

这是一个 **Human-in-the-loop** 系统。AI 负责提取、建议和生成，人类始终负责
确认和发布。任何阶段的内容都应该能够被查看、修改、退回或单独重新生成；
只有经过审核批准的模块才能发布到教学网站。

## 目标工作流

```text
上传资料
→ 解析并建立来源索引
→ Outline Agent 生成统一教学大纲
→ 创作者审核并确认大纲
→ 专业 Agent 分别生成四个教学模块
→ 分模块审核、修改或重新生成
→ 统一预览
→ 发布到现有网站
```

上传材料可以包括讲义、论文、教材许可片段、幻灯片、代码、数据集和实验说明。
系统需要保存材料来源，并尽可能让生成内容能够关联到支持它的原文证据。

## 统一数据来源

审核通过的教学大纲是所有下游模块共享的内容契约。它应包括：

- 学习目标；
- 前置知识；
- 核心概念；
- 术语和符号；
- 公式；
- 教学顺序；
- 示例环境；
- 实验目标；
- 来源证据。

四个 Agent 必须从同一份大纲和内容 Schema 生成内容，以减少 Theory、
Animation、Notebook 和 Experiment 之间的矛盾。如果大纲发生变化，系统需要
明确提示哪些下游模块可能已经过期，而不是自动覆盖已经接受的内容。

## Agent 分工

- **Outline Agent**：从上传资料中提取学习目标、前置知识、关键概念和教学顺序；
- **Theory Agent**：生成理论说明、公式解释、示例和总结；
- **Animation Agent**：生成视觉分镜和动画制作规格。动画可以借助 Manim 等
  工具制作，但需要经过人工核对；
- **Notebook Agent**：生成可执行、带注释的代码示例和学习练习；
- **Experiment Agent**：定义交互环境、参数、预期观察、实验步骤和展示数据。

每个 Agent 的输出都应包含来源依据、生成记录和校验结果。

## 审核与交互要求

创作界面采用分阶段流程，而不是一次性生成全部内容。用户需要能够：

- 查看每个模块的生成和审核状态；
- 修改文本或通过表单调整结构化内容；
- 只重新生成一个模块；
- 保留已经接受的其他模块；
- 比较修订版本；
- 查看来源证据；
- 在发布前预览最终网站效果；
- 只发布全部审核通过的内容。

普通用户不应直接编辑 JSON 等内部数据格式。用户填写表单，系统负责映射到
底层 Schema。

## 校验要求

系统需要自动检查：

- 必填字段是否完整；
- 不同模块中的术语、公式和符号是否一致；
- 内容是否能够关联上传资料；
- 文件结构是否符合平台规范；
- Notebook 是否可以执行；
- Experiment 接口和返回结果是否合法；
- Animation 规格是否完整；
- 是否存在未经审核或占位内容。

自动校验不能代替专家审核，只用于提前发现结构性和技术性问题。

## 技术方向

主要技术包括：

- **Python**：文档处理、Agent 编排、校验和发布；
- **大语言模型**：大纲及模块生成；
- **Retrieval/RAG**：让生成内容关联上传资料；
- **Manim**：程序化教学动画；
- **Jupyter Notebook**：可执行教学示例；
- **Gymnasium**：强化学习实验环境；
- **现有网站框架**：创作界面、预览、安装和内容发现。

系统应尽量复用现有网站的内容格式、导航结构和运行机制。

## 评估方式

项目既要评估技术正确性，也要评估实际创作价值，主要指标包括：

- 来源忠实度；
- 强化学习内容的事实正确性；
- 四个 Agent 输出的一致性；
- Notebook 执行成功率；
- Animation 和 Experiment 的有效性；
- 必填内容完整率；
- 专家审核通过率；
- 创作者对易用性、可控性和可信度的评价；
- 与原有人工流程相比节省的制作时间。

测试材料应覆盖不同长度和格式，并通过任务型可用性测试观察教师、助教和内容
作者能否在较少帮助下完成生成、审核、修改和发布。

## 一句话概括

本项目不是让 AI 自动发布课程，而是建立一个以统一教学大纲为中心、来源可
追溯、模块可独立审核和重新生成的 AI 辅助强化学习内容生产工作流。
